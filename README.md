# CSE Hackathon Projects

A collection of four algorithm-based projects developed using Python and Java. These projects demonstrate problem-solving skills, algorithm design, data structures, and graphical user interface development.

## Projects

### 1. Maze Solver
- **Language:** Python
- **Algorithm:** Breadth-First Search (BFS)
- Solves maze paths using graph traversal.
- Supports keys and doors as part of the maze-solving challenge.

### 2. Closest Pair of Points
- **Language:** Java
- **Interface:** Java Swing
- Finds the closest pair of points in a two-dimensional plane.
- Provides a graphical visualization of the points and their closest pair.

### 3. Budget Traveller
- **Language:** Python
- **Interface:** Tkinter
- **Algorithms:** Dynamic Programming and Dijkstra's algorithm
- Finds affordable flight routes using discount coupons.
- Compares route costs and algorithm performance.

### 4. Exam Timetable Scheduler
- **Language:** Python
- **Algorithm:** Graph Coloring
- Assigns exam time slots while avoiding scheduling conflicts between subjects with shared students.
- Provides a graphical interface for timetable scheduling.

## Technologies Used

- Python
- Java
- Tkinter
- Java Swing
- Graph Algorithms
- Dynamic Programming
- CSV Data Handling
